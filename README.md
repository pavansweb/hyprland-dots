# Hyprland Dotfiles

A comprehensive backup of my Hyprland configuration, including scripts, themes, and wallpapers.

## 🚀 Installation

> [!WARNING]
> These dotfiles are configured for my personal setup. It is highly recommended to back up your existing configuration before proceeding.

### 1. Clone the repository
\`\`\`bash
git clone https://github.com/pavansweb/hyprland-dots.git
cd hyprland-dots
\`\`\`

### 2. Copy Configuration Files
Copy the contents of this repository to your \`~/.config/hypr\` directory:
\`\`\`bash
mkdir -p ~/.config/hypr
cp -r ./* ~/.config/hypr/
# Remove the local git and Pictures folder from the config path if they were copied
rm -rf ~/.config/hypr/.git
rm -rf ~/.config/hypr/Pictures
rm ~/.config/hypr/README.md
\`\`\`

### 3. Setup Wallpapers
The wallpapers are stored in the \`Pictures/wallpapers\` directory in this repo. You should move them to your system's Pictures folder:
\`\`\`bash
mkdir -p ~/Pictures/wallpapers
cp -r Pictures/wallpapers/* ~/Pictures/wallpapers/
\`\`\`

### 4. Install Dependencies
Ensure you have the following installed:
- \`hyprland\`
- \`hyprlock\`
- \`hypridle\`
- \`waybar\`
- \`rofi-wayland\`
- \`swww\` (for wallpapers)
- \`grim\` & \`slurp\` (for screenshots)
- \`cliphist\` (for clipboard management)
- \`pyprland\`

### 5. Scripts
Make sure all scripts are executable:
\`\`\`bash
chmod +x ~/.config/hypr/scripts/*.sh
\`\`\`

## 🛠️ Features
- **Dynamic Themes:** Supports multiple themes like TokyoNight, Catppuccin, Everforest, etc.
- **Custom Scripts:** Includes scripts for wallpaper selection, brightness control, volume, and more.
- **Lockscreen:** Integrated \`hyprlock\` configurations.

A wide variety of wallpapers are included in the \`Pictures/wallpapers\` directory, ranging from Anime to Minimalist and Nature scenes.
